The framebuffer console uses Sun Gallant Demi, a 12x22 bitmap typeface. The upstream Go data is kept in gallant.go, and font.h packs each row into a 12-bit value for the framebuffer renderer. The source includes ASCII, Latin-1, and the replacement glyph; unsupported bytes use that replacement glyph. Copyright and license notices are in GALLANT-LICENSE.txt. The upstream project is https://github.com/dim13/gallant, and the source SHA-256 is f733c4bf442146a9ded38fbad5cbc48de0892661c55c58ec02cefacaf626f85e.
